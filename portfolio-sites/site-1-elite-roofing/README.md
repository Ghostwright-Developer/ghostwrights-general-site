# Elite Roofing Portfolio Site

Upload all your Elite Roofing website files here, maintaining the same folder structure from your project:

## Folder Structure

```
portfolio-sites/site-1-elite-roofing/
├── src/
│   ├── components/
│   ├── pages/
│   ├── App.tsx
│   └── main.tsx
├── public/
│   └── (images, assets)
├── package.json
├── vite.config.ts
├── tsconfig.json
├── tailwind.config.js
├── postcss.config.js
├── eslint.config.js
└── (other config files)
```

## How to Upload

1. Go to `portfolio-sites/site-1-elite-roofing/`
2. Upload all files from your Elite Roofing project maintaining this structure
3. Once uploaded, the portfolio page will automatically load your complete site in a modal

The site will be fully navigable and styled exactly as it appears in your local project.
